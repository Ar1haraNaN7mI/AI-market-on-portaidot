Trusted Delivery

Escrow, proof, accept, release

  1. Buyer creates the order and funds POT escrow.
  2. Seller accepts the order and prepares the delivery.
  3. Seller submits a hash, metadata, or signed artifact.
  4. Buyer verifies the proof and accepts delivery.
  5. Contract releases POT to the seller.

Portaldot fit

Portaldot provides the trust layer, gas, escrow settlement, and verifiable on-chain record.

Chain info

Websocket wss://mainnet.portaldot.io, SS58 42, genesis 0x83b5...8a54, POT uses 14 decimals, and the local node path is portaldot_dev --dev --alice.

Python SDK sidecar

npm run demo starts the Portaldot SDK service at http://localhost:8787/health when substrateinterface is installed.

Environment setup

npm run setup checks Python SDK, Rust components, wasm target, cargo-contract, and the C++ compiler requirement.

Explorer access

Use the official Portaldot explorer for live chain browsing, then switch to Local Node when testing against a local network.

MVP boundary

Focus on discover, order, escrow, proof, acceptance, release, and verification.
